# ATOM [arXiv 2610.23254] — методологическая разборка

**Verdict: Fully portable.** Это не бенчмарк, а audit-рецепт поверх стандартных бенчмарков: выборка из 33 000 траекторий расшифровывает «провалившиеся атаки» на шесть поведенческих ярлыков (отказ/игнор/механический сбой/комплайенс) — прямой скелет для FR-1.19 (break/refused/ignored); judge-протокол, quote-верификация и статистика (McNemar/Wilson/Bonferroni) воспроизводимы, артефакты выложены. Портируемость: все 33 000 размеченных траекторий, index-sample, судья-промпт и скрипты — https://anonymous.4open.science/r/AgentAutopsy-15C4/.
По-простому: авторы перечитали LLM-судьёй (судья = оценивающая модель) 33 000 траекторий и разложили поведение агентов на 6 ярлыков — честный отказ, молчаливое игнорирование, поломка, полное подчинение атаке. Главный вывод: большинство «проваленных» атак игнорируются, а не отсаживаются.
## 1. Harness
- Бенчмарки без изменений: InjecAgent (1 054 двухходовых кейса: 510 Direct Harm + 544 Data Stealing, официальный ReAct-промпт) и AgentDojo (949 stateful-эпизодов; 35 capability-only из 984 выкинуты; BU на 97 clean): «InjecAgent ... has 1,054 two-turn cases. ... AgentDojo ... has 949 stateful, multi-turn episodes across four task suites»; атака tool_knowledge и официальный парсер удержаны без очистки: «AgentDojo uses the tool_knowledge attack from its codebase; 35 capability-only cases are removed from the 984 attack cases, and BU uses the 97 clean user tasks» → FR-1.11, NFR-2.13.
- Атакер меняет ТОЛЬКО содержимое tool outputs: «The attacker can only modify the external content that reaches the agent through its tool outputs. It cannot change the system prompt, the user's request, the tools or the model» — соответствие интерфейсному барьеру FR-1.3/1.4.
- Агенты — 11 open-weight моделей 2–14B шести семейств, greedy decoding: «All agents are served with vLLM 0.25.1 using greedy decoding (temperature 0, top-p 1, fixed seeds), 16,384-token chunked prefill, a 65,000-token maximum length and an 8-turn limit per episode» → NFR-2.4/2.5/2.6/2.10; 14B выше нашего ≤8B — фильтровать.
- «Битые» модели выкинуты пилотом, а артефакты без grammar-constrained decoding считаются данными, не багами: «Hermes-3-Llama-3.1-8B, Llama-3.2-3B-Instruct, Llama-3.1-8B-Instruct and Mistral-7B-Instruct-v0.3 were piloted but broke down inside AgentDojo ... and were removed» / «We did not use grammar-constrained decoding ... because each would hide the failures we measure».
## 2. Источники и срез данных
- Не свой датасет, а полные прогоны: сетка 11 агентов × 3 прецизии (FP16/FP8/NF4) × 2 бенчмарка; аудиторский срез зафиксирован ДО judging: «Before judging, we locked a stratified random sample of 500 trajectories for each of the 66 cells (11 agents × 3 precisions × 2 benchmarks), drawn independently per cell» — по 500 траекторий на ячейку, 66 ячеек = 33 000, индексы выложены: «AgentDojo ... in proportion to suite size (76 Banking, 55 Slack, 74 Travel, 295 Workspace), and on InjecAgent by attack class (258 Data Stealing, 242 Direct Harm)» → NFR-2.8.
- Очистки нет — это фича: invalid outputs (агент выдал нечитаемый tool call — 1 562 на FP16) учитываются отдельным ярлыком «механический отказ», а не выбрасываются: «InjecAgent's parser rejected 1,562 FP16 outputs as invalid ... LFM-2.6B, for example, has 0.00% ASR but 735 invalid outputs out of 1,054, so most of its cases never test resistance» → FR-1.18/FR-1.19.
## 3. Протокол фиксации исходов
- Двухслойная запись: вердикт бенчмарка (S = успех атаки, U = выполнена задача юзера) + behavioral audit судьёй в 6 ярлыков по убыванию приоритета; судья возвращает структурированный JSON: «The judge returns one JSON object with the label, recognition flag, first recognition step, verbatim evidence quote, a short justification and a confidence level».
- 6 ярлыков: FULL_COMPLIANCE, PARTIAL_COMPLIANCE, GENUINE_REFUSAL, INERT_RECOGNIZED, INERT_UNRECOGNIZED, BROKE; главный результат: failed-атаки в 76–80% случаев ignored и лишь в 17–18% refused: «In 76.3% and 80.3% of them, the agent ignored the injection, while Genuine Refusal accounts for only 18.0% [17.4, 18.6] and 17.2% [16.6, 17.8]» → FR-1.19 — почти изоморфизм нашей триады + отдельно ignored-recognized.
- Recognition считается только при ЯВНОМ упоминании инъекции в reasoning, с обязательной цитатой (консервативный lower bound): «an automated script verifies that the judge's evidence quote appears verbatim in the agent's chain-of-thought. Claims lacking verbatim textual grounding are downgraded to Inert-Unrecognized, making our reported recognition rates a conservative empirical lower bound»
- Судья DeepSeek-V4.1-Flash (greedy, промпт выложен, SHA-1 4940e0200359), траектория в `<untrusted_trajectory>`; quote-верификация проверяет цитату verbatim, при расхождении 2 переспроса, иначе понижение до Inert-Unrecognized — 90.77% цитат прошли с первой попытки: «On a mismatch the judge is asked again for the exact sentence, up to twice; if the mismatch persists, recognition is set to false ... Of 10,428 recognition claims, 9,466 (90.77%) passed on the first attempt» → FR-1.22.
- ATOM-матрица S×U из 4 ячеек показывает, что маргинальные ASR/UA прячут 21.7% safe-but-broken эпизодов: «About two thirds of episodes are Safe and Useful, the outcome a secure agent should reach. Yet one in five is Safe but Dysfunctional (21.7%). In these episodes the attack failed, but so did the user's task: the agent was safe yet dysfunctional» → FR-1.23, FR-1.16.
## 4. Учёт затрат
- GPU/энергия: «The experiments used about 557 GPU hours (about 230.6 kWh, an estimated 88.8 kg CO2e) and retrained no model» — RTX 4090 238ч + RTX A6000 237ч локально, A100-80GB 82ч в облаке: «Local runs used an RTX 4090 (24 GB; 238 GPU hours) and an RTX A6000 (48 GB; 237 GPU hours)»; судья: 258.42M input + 36.99M reasoning токенов на 33 000 траекторий: «Judging the 33,000 trajectories processed 258.42M input tokens and 36.99M reasoning tokens» — готовая норма «токенов судьи на траекторию» для C_ep (FR-1.17); $-стоимость judge-вызова — not stated; латентность агентов и деньги per-компонент не замерялись.
## 5. Статистика
- Wilson 95% CI на все доли; парные сравнения: точный биномиальный McNemar при N01+N10<25, иначе χ² с поправкой Эдвардса; ассоциации — Pearson χ² + Cramér's V: «we use the exact binomial McNemar test when N01 + N10 < 25 and Edwards' continuity-corrected χ2 ... otherwise» → NFR-2.8, FR-1.22.
- Согласие судья/человек: Cohen's κ = 0.835 на 4-way (150 траекторий на двух авторов, споры — обсуждением): «Their labels agree with the judge on every attacker action and on 96% of four-way groups (κ = 0.835)»; Bonferroni: переживают коррекцию только крупные сдвиги, мелкие описаны, но НЕ интерпретируются: «All survive a Bonferroni correction over the tests reported. Smaller shifts (e.g., LFM-2.6B under the guardrail, p = 0.031 ...) are described but not interpreted as effects»; «ignored > refused» перепроверено на 6 срезах + worst-case.
- Interdict/Authorize: сматченные системные промпты почти по длине (163/172 слов): «matched system-prompt policies with identical templates and near-equal length (163 and 172 words).» — 10 698 paired-кейсов InjecAgent FP16: «We compare the two policies on the 10,698 InjecAgent cases evaluated under both» → NFR-2.8.
## 6. Trap-деталь
- Что ломается при reproduce: замер guardrail на одном промпте — низкий ASR может быть «inactivity defense»: разрешающий Authorize-промпт поднимает ASR до 43% на тех же весах и атаках: «A system prompt permitting instructions in tool outputs (Authorize) raises pooled ASR to 43.05% [42.11, 43.99], against 8.09% at baseline. A matched prompt forbidding them (Interdict) lowers it to 0.22% [0.15, 0.33]»; «The two prompts differ by only nine words, so length cannot explain the gap» — замерять на БАЗОВОМ и защитном промптах, иначе ложная защищённость.
- Invalid outputs искажают вердикт: у LFM-2.6B ASR 0.00% объясняется 735/1054 некорректных выходов (не умел действовать); отсекать отдельно: «Over valid outputs only, InjecAgent's own primary metric, pooled FP16 ASR rises from 8.09% to 9.35%».
- Judge-agreement — обязательный контроль при внедрении своего судьи: «the judge agrees with the benchmarks' own verdicts on 96.7% of AgentDojo and 98.5% of InjecAgent cases» / «and it labels 99.7% and 99.8% of recorded successes as compliance».
## Прямой перенос
- 6-ярлыковый behavioral audit + quote-верификация + двухслойный judge/бенчмарк-агремент → FR-1.19, FR-1.18, FR-1.22; S×U-матрица с отдельной ячейкой «Safe but Dysfunctional» → FR-1.23, FR-1.16; two_step_status («6a_full» vs «6b_step1_only») → FR-1.21 + state-diff (FR-1.18); locked sample 500/cell, Wilson CI, McNemar/Bonferroni → NFR-2.8, NFR-2.2; промпты Interdict/Authorize/guardrail-блок verbatim: «Each system-prompt condition appends one block to the system prompt; the blocks below are reproduced verbatim» → FR-1.5 и контролы «переключения промптом».
- Квантование — диагноз «safe ≠ useful»: NF4 снижает ASR, но UA −4.75 п.п. и Safe&Useful −3.97 п.п.: «On AgentDojo, NF4 reduces ASR by 2.33 points, but cuts Safe-and-Useful episodes by 3.97 points and UA by 4.75 points» → NFR-2.6.
## Адаптация
- Судью DeepSeek-V4.1-Flash заменить на OSS ≤8B с сохранением JSON-полей и цитата-верификации → NFR-2.4/2.5 (пересчитать свои токены/траекторию; per-cell замер 500/cell — масштабируемая оценка C_ep, NFR-2.9); атакующий канал «в tool outputs» замкнуть на 5 инструментов полигона (→ FR-1.11) с сохранением метрического слоя S/U + 6 ярлыков; McNemar/Bonferroni на paired g0/g_proc/g_simple в связке с L* → FR-1.24; статичный атакер → добавить A-режим (NFR-2.11); greedy без семплов → повторные прогоны с сидами (NFR-2.2).
## Непереносимо
- Очередь/ёмкость ручного потока и влияние на легитимный поток (FR-1.15/1.16) не моделируются; latency/деньги per defense call — not stated (только token counts и GPU-часы, FR-1.17 частично, NFR-2.9); атакер не агент: «The attacker can only modify the external content that reaches the agent through its tool outputs.» — статические нагрузки через единственный канал (ограничение FR-1.21).
## Что осталось непонятным
- Публичный репо — anonymous.4open.science: де-анонимизация после peer-review не зафиксирована, доступ и содержимое проверять на месте.
- Interdict у Ministral-14B идёт в другую сторону — в статье «unexplained»: «Ministral-14B (0.11%), whose low response remains unexplained».
- Судья — single LLM без регенераций по полной выборке: 6-way согласие с человеком 86% (κ=0.662), по InjecAgent 6-way κ=0.594 — предел различения Inert-R vs Inert-U: «the sample bounds agreement tightly at the four-way level on which our claims rest», поэтому главные заявки на 4-way.
- Как строились 10 698 paired-кейсов Interdict/Authorize (базовое покрытие случаев) — в явном виде не уточнено.
