# Gate AI [arXiv 2606.02959] — методологическая разборка

Verdict: Partially portable. Статистический каркас (единая глобальная рабочая точка, контроль утечек, стратифицированный bootstrap CI, сравнения при выровненном FPR) — готовый шаблон для paired-сравнений полигона, но сам артефакт — оценка одного закрытого каскадного детектора на статических промптах: без среды, без очереди, без кода. Портируемость: репозитория нет, детектор проприетарный; воспроизводимость держится только на формулах статьи и публичных датасетах.
По-простому: Авторы прогнали один закрытый каскадный детектор инъекций по 16 публичным наборам задач и выставили один общий порог срабатывания. С конкурентами их сравнили при одинаковой доле ложных срабатываний (FPR).

## 1. Harness
- Детектор — чёрный ящик (каскад-ансамбль); 16 публичных бенчмарков через source-tagged loader сливаются в единый trace: «16 public benchmarks (12,111 samples)... The evaluation trace combines 16 public benchmarks covering balanced collections, all-attack adversarial corpora, and all-benign over-defense benchmarks»; идентичность = content-hash версий загрузчиков + капы сэмплов: «Trace identity is content-hashed over the loader file contents and a per-loader sample cap, so re-runs against the same loader version and cap produce bit-identical traces»; измеряют OOF-предсказания: «Every headline metric (F1, precision, recall, FPR, AUC) is reported with a 95% stratified bootstrap confidence interval».
- Латентность би-модальна: p50 53 мс, p99 612 мс; «The distribution is bimodal — a fast-mode cluster (≈90% of requests, first stage only) and a deferred-mode tail (≈10%) that incurs a second per-request analysis step. Numbers are saturation-free percentiles on warm pods; cold-start, bursty-queue contention, and cross-AZ jitter are not modelled».

## 2. Источники и срез данных
- 16 датасетов, 12 111 сэмплов; срез по типу датасета: Direct prompt injection 4,662 / 38.5%; Indirect 1,525 / 12.6%; Gandalf 777 / 6.4%; Over-defense (all-benign) 1,310 / 10.8%; Harm / jailbreak 3,837 / 31.7%.
- 3 синтетических датасета вне headline: «3 synthetic datasets are excluded from this headline trace and from every metric reported in Sections 4–5; they appear only in the OOF diagnostics, where they sanity-check threshold transferability»; primary metric per датасет: «the metric the dataset was designed to be scored on — F1 for balanced splits, Recall for all-attack collections, ODA = 1-FPR for all-benign probes»; self-оценки — верхняя граница: «Self-evaluations are marked with an asterisk and treated as upper bounds because the competitor’s training split may overlap the dataset»; conflicting labels ловятся хэшем near-duplicates: «Cross-source near-duplicate hashing catches prompts that appear in multiple datasets under conflicting labels... and surfaces them for manual relabel» → ручная переразметка.

## 3. Протокол фиксации исходов
- Вероятности — max-pool по чанкам → глобальный порог θ: «the single global threshold \tilde{\theta}=\operatorname{median}_{k}\theta_{k}^{*} applied to the max-pooled probability»; AUC — по пуллированной вероятности без порога («AUC comes from \hat{p}_{p} (threshold-free)»); промпт = чанк, агрегация вырождается в тождество: «every prompt fits in a single chunk so this aggregation reduces to identity (|C(p)|=1 for all p)».
- Одна глобальная рабочая точка: «A single global operating point applies uniformly to every dataset. There is no per-dataset threshold tuning and no per-dataset hand-tuned decision rule», θ_op = argmax F1 при FPR ≤ τ = 1%, подбор только на OOF: «solved by exhaustive search over a coarse-but-well-spread candidate grid on out-of-fold predictions»; порог публикуется: «The threshold is reported alongside the document so the operating point is auditable»; вердикт бинарный allow/block, refused/ignored нет (это не проговорено в тексте). Точку Lakera (FPR 0.1–0.2%) не сравнивают: «advertises an FPR as low as 0.1–0.2%. That figure comes from Lakera’s internal Challenging Moderation Benchmark, with the model’s adaptive-calibration tuned per customer as part of onboarding».

## 4. Учёт затрат
- Латентности p50/p90/p95/p99/p99.9/max/mean на production-железе: «per-stage samples come from concurrency sweeps on the production hardware, and the per-request composite is drawn under the cascade’s actual exit policy»; конкурентные — среднее по опубликованным per-dataset числам («Gate’s marker uses the median competitor latency as a presentational fallback»).
- Деньги не моделируются: «latency, throughput, and serving cost are reported separately... and are not part of this matched-FPR claim» → C_guard/C_ep — собственный журнал полигона, принцип раздельного отчёта с CI → FR-1.17, NFR-2.9. Разложение по компонентам не ведётся (в тексте нет ни одного per-component cost-числа).

## 5. Статистика
- Headline — 5-fold StratifiedKFold; диагностический сплит — StratifiedGroupKFold по ключу: «a parallel StratifiedGroupKFold pass over a composite key (parent-prompt id plus MinHash + LSH near-duplicate clusters at Jaccard \gtrsim 0.8) runs alongside it as a leakage-premium»; ΔF1 = leakage-премиум.
- Inner-fold: 85/15, early stopping (800 итераций, patience 40, log-loss): «The inner-valid slice is the early-stopping monitor (max 800 iterations, patience 40, log-loss on the inner-valid slice as the stopping criterion) and the operating-threshold selector»; θ из сетки наблюдаемых ∪{0.3…0.9}: «\Theta_{k} is the union of all observed inner-valid probabilities and a fallback grid \{0.3,0.4,0.5,0.6,0.7,0.8,0.9\}», канонический — медиана фолдов; integrity-батарея: «Under shuffled labels: AUC = 0.5146, F1 = 84.44%» (случайность), «A strong |\rho|>0.3 flags a shallow detector» (length-bias), LODO, Cohen κ голов: «Empirical: pairwise \kappa\in[0.45,0.56] across 3 head pairs», adversarial validation AUC≈0.5 («A well-balanced split yields \mathrm{AUC}(g_{\phi^{*}})\approx 0.5»), paraphrase-invariance (_fig 11_).
- Bootstrap: «Every headline metric... is reported with a 95% stratified bootstrap confidence interval», страты источник×лейбл («(s,y)\in\mathcal{S}\times\{0,1\} (source \times label)»), B = 10 000, 95% percentile CI; n<200 = small-n; порог пересобирается per-resample: «rows whose draws also re-pick \theta widen the CI to include the threshold-selection uncertainty» (double dipping, Cawley & Talbot); ECE/Brier после изотоники, 15 бинов («M=15 equal-width confidence bins»); subsample до n конкурента: «For every competitor that published a smaller n than ours on the same dataset, we draw B subsamples of size n_{theirs} from our out-of-fold predictions and bracket the comparison with a 95% percentile interval» — «в пределах шума».

## 6. Trap-деталь
- Где расколются репликаторы: сплиттер. Обычный GroupKFold смешал утечку с дисбалансом классов: «The earlier paper revision used plain GroupKFold for this diagnostic; that conflated leakage with class-marginal imbalance across folds (GroupKFold does not stratify by label)»; ΔF1 стала бесполезно широкой: «turned \Delta F_{1} into a loose upper bound»; StratifiedGroupKFold изолирует чистую утечку, а при вырождении ключа ΔF1 явно объявляют неинформативной: «\Delta F_{1} is uninformative in that regime; we say so explicitly to avoid claiming protection the diagnostic cannot provide».
- Второй разлом — matched-FPR: «every per-dataset competitor entry that publishes both a primary metric and an FPR is also surfaced with our value re-evaluated at the threshold whose FPR matches theirs on that dataset»; там, где первичная метрика сама есть FPR (†): «matching FPR collapses the comparison; our value at the global headline threshold is shown instead and tagged †»; где метрики без FPR (‡) — 1%-ный суррогат: «our threshold is matched to a 1% FPR surrogate rather than the competitor’s unknown operating point».

## Прямой перенос
- Content-hash trace identity + JSONL-чекпойнты с детерминированным replay: «Intermediate artifacts are checkpointed to JSONL so downstream metrics replay deterministically from the recorded artifact», единый SEED-констант: «Every randomised step in the evaluation pipeline is seeded from a single SEED constant» → NFR-2.2.
- Единая глобальная точка с публикацией порога: «The threshold is reported alongside the document so the operating point is auditable»; matched-FPR refit: «re-evaluated at the threshold whose FPR matches theirs»; over-defense probe (1−FPR) → NFR-2.8, FR-1.22.
- Стратифицированный bootstrap CI + «в пределах шума» (subsample-B-интервал); батарея integrity-диагностики: «a battery of diagnostics (leave-one-dataset-out cross-validation, a random-label control, adversarial validation, permutation feature importance, length-bias correlation, classifier-head agreement...)» → FR-1.23, NFR-2.13.

## Адаптация
- ΔF1-утечка → общие префиксы/инструменты attacker и benign-эпизодов под групповым ключом «(parent-prompt id plus MinHash + LSH near-duplicate clusters...)» → NFR-2.8; LODO — «leave-one-dataset-out cross-validation» → контроль g на доменах вне g_proc → NFR-2.12.
- Subsampling до n конкурента: «bracket the comparison with a 95% percentile interval» → выровненный по объёму контакт режимов D vs A, CI без пере-подбора порога → FR-1.20, NFR-2.11.
- Би-модальная латентность: «a fast-mode cluster (≈90% of requests...) and a deferred-mode tail (≈10%) that incurs a second per-request analysis step» → эскалации в ручную очередь как deferred-режим, учёт в Q(g) → FR-1.15, FR-1.16, FR-1.17.

## Непереносимо
- Детектор проприетарен, код харнесса не опубликован — воспроизводимость только самостоятельной реализацией: в тексте нет ни одного URL кода, только «refer to the most recent version for current figures» — только общая лицензионная сноска.
- Нет среды: «The current evaluation covers text inputs» (vision gap); список Coverage gaps явно перечисляет отсутствующие агентные каналы — «Voice-channel jailbreaks (audio prompts transcribed inside the agent loop). Tracked as follow-up but not in this report» и др. [Coverage gaps]; агент, тулы, очередь, мульти-ходы, cross-turn не представлены.
- Адаптивный атакующий против замороженного снапшота — future work: «competitive evaluation against an active attacker who queries the detector before crafting their payload is left for future work»; в полигоне это ядро режима A [Coverage gaps].

## Что осталось непонятным
- Значение SEED не названо; в тексте только «a single SEED constant» без числа.
- Гиперпараметры каскада и состав голов не раскрыты: «Head names are anonymised in the rendered figure».
- Обоснование τ = 1% — только «1% approximates the operator-reported false-alarm rate above which downstream users report alert fatigue and start ignoring or bypassing the detector», без источника.
- Paraphrase-invariance probe количественно не описан: «a paraphrase-invariance check bounds how lexically-shallow the final-stage signal is» — это всё, что есть.
- Реестр 16 датасетов сведён только в разрезе по семействам с %; per-loader cap-значения в одну таблицу не собраны (loader, cap — по одному числу в тексте).
