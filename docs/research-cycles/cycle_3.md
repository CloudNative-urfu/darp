# Цикл 3 — C3-H3: obligation-scoped остановка бесплодных повторов

Цикл построен вокруг идеи: **не давать агенту бесконечно повторять одно и то же бесполезное действие по одному и тому же обязательству, пока не появится новое релевантное событие от хоста**. Prerequisite — C3-H1: feasibility управления reasoning и компактного интерфейса.

### 1) Обзор литературы и выбор гипотезы

| Решение | Описание |
|---|---|
| **16 источников** | Patterns, GoEx, SIEVE, ARGUS, MENTOR, Bounded Agents, From Shield to Target v2, Möbius Injection v2 и др.; 13 поисковых запросов. |
| **Прямой аналог найден** | `Ericsson/yocto-security-tools` (no-information turns) — прямой инженерный аналог S10; оснований заявлять новую архитектуру нет, он включён в сильные сравнения. |
| **Дефект источника** | У CCRM обнаружено внутреннее расхождение знаков в доказательстве; численные теоремы не используются как подтверждённые факты. |
| **Выбрана C3-H3** | Прерывание повторов без новой информации; сильный S10-style baseline обязателен, эквивалентность с ним запрещает заявление нового механизма. |

### 2) Протокол (заморожен)

| Решение | Описание |
|---|---|
| **Выборка** | N=192 независимых семейства, по два final-повтора на clean/own-adaptive arm; transfer отдельно. |
| **Grid порогов** | H и B-progress проверяются на одинаковых порогах r ∈ {1, 2, 3} — сильный default baseline (S10 threshold=3) сохранён. |
| **Ограничения** | max_tokens фиксирован на 2048; reasoning R0/R1/R2 — как неизвестный pass-through. |
| **Бюджет (потолок)** | 27 762 logical / 29 151 physical calls; 298 506 240 admission tokens; 1 749 060 active seconds. |
| **Чувствительность** | При N=192 и нуле вредных discordances safety upper = 0.01903; при одном — 0.02868 (margin 0.02 не проходит). |

### 3) Реализация MVP

| Решение | Описание |
|---|---|
| **Код с нуля** | `mvp/domain.py`, `store.py`, `host.py`, `deterministic.py`, `policies.py`, `runner.py`, `transport.py`, `feasibility.py`, `attacks.py`; SQLite объединяет commit-очередь и append-only event в одной транзакции. |
| **Строгие парсеры** | Full/compact parser не чинит JSON и не извлекает ответы из reasoning. |
| **Политики** | D0, H, task-level B-progress, B-loop, B-fresh, B-cap и др.; различение нового prerequisite активного обязательства и прогресса другого поля. |
| **Тесты** | **45/45 passed**, включая 243 последовательности host events в одном property-тесте; 15 scripted траекторий с ожидаемыми исходами. |

### 4) Блокировка live-экспериментов

| Решение | Описание |
|---|---|
| **Resource gate** | Frozen protocol требует до feasibility подтверждённые 120 физических запросов, 1 228 800 admission tokens и 7 200 active seconds. **Quota commitment не предоставлен** — паспорт модели квоту не удостоверяет. |
| **114 решений о незапуске** | Все 114 условных feasibility-слотов получили `admission_blocked` в append-only dispatches.jsonl: `dispatched=false`, usage/cost=null. Это **0 модельных вызовов**, не 114 отказов API. |
| **Дефект поставки** | `dispatches.jsonl` был пуст (0 bytes), а verifier требовал пустой список — PASS не подтверждал контракт. Исправлено: непустой ledger, полное покрытие слотов, отказ при вымышленных request-записях. |

### 5) Scripted-контрасты и итог

| Контраст | Результат |
|---|---|
| **H(r=3) vs B-progress(r=3)** | H — 3 turns, SFC=false; B-progress — 4 turns, SFC=true. |
| **H(r=1) vs B-cap(2)** | H останавливается после 1 turn (потеря repair); B-cap исправляется после 2. |

- **Экономия числа обращений здесь сопровождается потерей полезности** — преимуществом H это не является.
- **Статус: live-эксперименты заблокированы отсутствием обязательных ресурсов**; C3-H1/C3-H3 не проверены живыми данными, статистического опровержения нет. API calls/tokens/cost = 0; efficacy N = 0.
- **Побочные продукты**: исполняемый offline MVP, 45 тестов, 15 траекторий, честный ledger из 114 admission decisions, memory.json (13 facts / 7 failures / 6 unknowns / 5 next).
- **Следующее направление**: выполнимый интерфейсный feasibility, затем предельная безопасная полезность bounded repair против сильных D0/one-shot/cap/progress.
