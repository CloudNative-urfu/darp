# Цикл 1 — H1: bounded dependency-local fresh-context recovery

Цикл построен вокруг идеи: **при запрещённом предложении не переиспользовать заражённый контекст, а откатить только затронутый результат и все его транзитивные зависимости, сохранив независимую работу** (fresh-context + локальная инвалидация).

### 1) Обзор литературы и выбор гипотезы

| Решение | Описание |
|---|---|
| **16 источников** | AgentDojo v3, CaMeL v2, PromptArmor v1, MELON v4, Adaptive Attacks v2, Fides v1, AgentSpec v3, GoEx, Task Shield (HTML-препринт), MENTOR, From Shield to Target, RETA и др. Все URL ответили HTTP 200, сохранены raw/текст/SHA-256. |
| **Пересечения подтверждены** | GoEx уже обсуждает selective undo/checkpoints/atomicity; MENTOR даёт guidance после блокировки; From Shield to Target прямо пересекается с атакой на цену защиты. Эти механизмы нельзя называть новой идеей цикла. |
| **Выбрана H1** | Bounded dependency-local fresh-context recovery. Выбор условный: эффект и новизна не установлены. |
| **Отклонены** | H2 (shared-serving availability) — нет контроля инфраструктуры; H3 (atomicity) — известная инфраструктура; H4 (guidance) — сильный конкурент из MENTOR. |

### 5) Итог

- **Статус: `inconclusive_confirmation_blocked`.** Подтверждающий эксперимент не выполнен: structured-JSON/attack-generation feasibility не пройдена, нет независимых семейств, Bstar, полного confirmation-датасета и подтверждённого ресурса.
- **H1 ≡ B4**: обе политики в одном множестве `FRESH` в runner, ветви одинаковы — добавочного механизма нет, контраст вырожден.
- **Учёт**: 125 API-вызовов, 280 852 известных токена, известный cost 0.0518020272; 10 ответов с неизвестным usage + 1 возможный in-flight (полная цена — null, не ноль).
- **Побочные продукты**: replay-инфраструктура (проверка из чистой копии, 34 теста + аудит 31 траектории), честный раздельный учёт расходов, memory.json (11 facts / 6 failures / 6 unknowns / 5 next).
- **Дефект поставки (повторяющийся паттерн кампании)**: обязательные `artifacts/sources.json` и `artifacts/memory.json` отсутствовали при «успешном» verifier, который проверял только корневые пути. Исправлено с регрессионными негативными проверками.
- **Следующее направление**: D0 на покрытом языке; детерминированное извлечение с изолированной LLM только для неразрешённых смысловых полей.
