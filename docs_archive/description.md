# Применение ИИ агентов для автоматизации атаки и защиты

## Описание:

### Актуальность:
Автономные ИИ-агенты кардинально меняют ландшафт кибербезопасности, требуя новых подходов к тестированию и защите инфраструктуры.

### Этапы:

1. Проектирование изолированного полигона и gym-like среды для RL и LLM-агентов.
2. Интеграция инструментария: атакующая сторона (Kali Linux), защищающаяся (open-source мониторинг). Настройка переключения LLM с трекингом токенов и хранилищ.
3. Сбор датасета атак и дообучение (fine-tuning) LLM для обхода базовых моделей.
4. Создание и валидация защитного LoRA-адаптера.
5. Подготовка статьи.

### Инструменты:
- Python
- LangChain/AutoGen
- Docker
- Kali Linux
- Wazuh/ELK
- Hugging Face
- PEFT (для LoRA)
- Gymnasium

### Источники:
- arXiv (разделы AI Agents in Cybersecurity, LLM for Penetration Testing)
- документация AutoGen/LangChain
- база MITRE ATT&CK.

Предусмотреть возможность выбирать различные LLM (локальные и облачные, с контролем потребления токенов, хранилища данных и другие инструменты агента, чтобы сравнивать конфигурации между собой). Предусмотреть минимальный набор инструментов для атаки (Kali и предустановленный софт), на стороне защиты: open-source системы мониторинга с минимальными предустановленными правилами обнаружения.

Предусмотреть дообучение LLM, чтобы обойти по качеству mythos. Результатом дообучения должно стать создание защитного LoRA адаптера для обнаружения атак с помощью LLM.

## Цель:
Целью проекта является исследование и практическое применение ИИ-агентов для автоматизации процессов кибербезопасности, включая обнаружение уязвимостей и организацию защиты. Предстоит спроектировать и развернуть инфраструктуру локального изолированного полигона, который позволит моделировать атакующие и защищающие стороны. В рамках работы необходимо реализовать гибкую архитектуру, поддерживающую интеграцию различных локальных и облачных LLM с контролем потребления ресурсов и токенов. Отдельным направлением станет дообучение языковых моделей для создания специализированного защитного LoRA-адаптера, способного детектировать атаки и превосходить базовые нефайнтюненные аналоги. Итогом станет формирование доказательной базы эффективности различных конфигураций агентов в условиях киберконфликта. Полученные результаты необходимо изложить в статье.

## Требуемый результат:
По итогам работы команда представит работающий Proof of Concept (PoC) в виде демонстрационного изолированного полигона с реализованной gym-подобной средой для тестирования агентов. Вторым ключевым продуктом станет обученный защитный LoRA-адаптер, интегрированный в систему мониторинга для детекции аномалий и атак. Третьим результатом будет подготовленная обзорная научная статья, систематизирующая современные подходы к использованию ИИ-агентов в задачах наступательной и оборонительной кибербезопасности.

## Критерии оценки:
- Продемонстрирован работающий PoC изолированного полигона с gym-средой, поддерживающий переключение между различными конфигурациями LLM (локальные/облачные) и инструментами (Kali, open-source мониторинг).
- Представлен и протестирован защитный LoRA-адаптер, показывающий улучшение метрик детекции атак по сравнению с базовой моделью.
- Подготовлен и оформлен драфт обзорной научной статьи с анализом эффективности различных конфигураций ИИ-агентов.
